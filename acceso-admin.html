Ingreso admin

Panel del propietario. Tiene una contraseña diferente al ingreso usuario y funciona únicamente en este equipo mediante el servidor local.

Seguridad y sesiones

Abrir panel de contenido como admin

Esta acción cierra los ingresos en otros equipos y revoca códigos y enlaces pendientes. Conserva esta sesión de propietario.

Restablecer acceso del usuario

El propietario puede restablecer el acceso aunque no funcione el correo. El envío de enlaces y avisos necesita SMTP configurado.

Cambiar mi contraseña de admin

Recibirás un enlace para escribir y confirmar la nueva contraseña. Si ya hay un correo registrado, la confirmación se envía a ese correo antes de modificarlo.
