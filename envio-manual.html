WhatsApp · envío manual

Carga tu lista, abre un contacto y envía desde WhatsApp. Después vuelve aquí y márcalo como enviado. Este modo no utiliza Render ni la API de pago.

1. Preparar lista y mensaje

La carga nueva reemplaza la lista actual después de confirmarlo. Se eliminan duplicados. Revisa los números antes de contactar.

WhatsApp abrirá con el texto preparado. La imagen debes adjuntarla tú en cada chat; no se adjunta automáticamente.

2. Contacto actual

Abrir un chat no confirma el envío. «Enviado» es una marca tuya, no una confirmación de entrega de WhatsApp.
