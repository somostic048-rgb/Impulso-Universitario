Mensajería y atención

Importa contactos, envía mensajes y atiende las dudas del chatbot.

La clave se mantiene solo en esta página y se envía al servidor. Usa HTTPS al publicar.

1. Importar contactos

Listas guardadas

Se conservan las listas importadas. Máximo 1.000 contactos por lista y envío.

Máximo 10 MB. Word antiguo .doc debe convertirse a .docx. PDF escaneado necesita OCR previo. Revisa las cifras detectadas: pueden incluir datos que no sean contactos.

2. Revisar y enviar

Vista previa del mensaje

Con imagen, el mensaje admite hasta 1024 caracteres y la imagen hasta 5 MB.

La plantilla debe tener una variable de texto {{1}} en el cuerpo. Si adjuntas imagen, debe tener encabezado de imagen aprobado.

    “Aceptado” significa que la API recibió el mensaje. La entrega requiere confirmación por webhook. No se reintentan envíos automáticamente.

    Personalizar chatbot

    Los cambios se aplican al abrir o recargar la web pública. El avatar admite emojis y símbolos; puedes elegir las animaciones disponibles sin modificar código.

    Preguntas frecuentes del chatbot

    El bot responde con este contenido. Añade palabras clave separadas por comas. Si no encuentra una respuesta clara, ofrece atención humana.

    Formato: [{"question":"Pregunta", "answer":"Respuesta", "keywords":"palabra,tema"}]

    Consultas para administradores

    El enlace de WhatsApp abre una conversación para que un administrador contacte al cliente.
